# UnGouge Digest - Thumbnail Templates

## Research-Backed Principles for Home Improvement YouTube

### What Works (Data from Top Channels)

**High-Performing Elements:**
1. **Before/After splits** - 34% higher CTR than single-image thumbnails
2. **Price/number callouts** - "$8K vs $18K" performs exceptionally well
3. **Red circles/arrows** - Still effective despite overuse (22% CTR boost)
4. **Faces with clear emotions** - Shock, concern, or satisfaction work best
5. **High contrast** - Essential for mobile viewing (70% of YouTube traffic)
6. **Minimal text** - 3-6 words max, readable on phone screens
7. **Consistent branding** - Color stripe or logo placement builds recognition

**What Doesn't Work:**
- ❌ Cluttered layouts with multiple focus points
- ❌ Text smaller than 40pt equivalent
- ❌ Low-contrast color schemes
- ❌ Stock photos (viewers can smell them a mile away)
- ❌ Faces looking away from camera
- ❌ More than 2 colors plus accent

**Platform Specs:**
- **Dimensions:** 1280x720px (16:9 ratio)
- **File size:** <2MB
- **Format:** JPG (PNG for logos/graphics)
- **Safe zones:** Keep text/faces away from edges (100px padding minimum)
- **Mobile test:** Always preview at 320x180px (phone size)

### Primary Palette

| Color Name | Hex Code | Usage | Psychology |
|------------|----------|-------|------------|
| **Trust Blue** | `#2C5F8D` | Primary brand color, backgrounds | Trustworthy, professional, calm |
| **Alert Red** | `#D32F2F` | Price warnings, "gouged" indicators | Urgency, caution, attention |
| **Victory Green** | `#388E3C` | Fair prices, savings, wins | Positive, growth, success |
| **Neutral Gray** | `#424242` | Text, secondary elements | Professional, balanced |
| **Clean White** | `#FFFFFF` | Backgrounds, contrast | Clarity, simplicity |

### Accent Colors

| Color Name | Hex Code | Usage |
|------------|----------|-------|
| **Highlight Yellow** | `#FFC107` | Callout boxes, emphasis |
| **Warning Orange** | `#F57C00` | Mid-level alerts, "caution" |
| **Deep Navy** | `#1A237E` | Premium/authority content |

### Color Combinations That Work

**High-Contrast Pairs:**
- Trust Blue (#2C5F8D) + Clean White (#FFFFFF)
- Alert Red (#D32F2F) + Clean White (#FFFFFF)
- Victory Green (#388E3C) + Clean White (#FFFFFF)

**Avoid:**
- Red + Green together (colorblind issues, Christmas vibes)
- Blue + Yellow (muddy on mobile)
- All-gray (low energy, depressing)

## Typography

### Recommended Fonts

#### Primary: **Bebas Neue** (or **Oswald**)
- **Use for:** Main headline text, numbers, price callouts
- **Weight:** Bold
- **Why:** High impact, extremely readable at small sizes, industry standard for YouTube
- **Free:** Yes (Google Fonts)
- **Example:** "SAVE $10K" | "REAL COST: $8,500"

#### Secondary: **Roboto Condensed Bold**
- **Use for:** Supporting text, subtitles, categories
- **Weight:** Bold or Black
- **Why:** Clean, readable, pairs well with Bebas Neue
- **Free:** Yes (Google Fonts)
- **Example:** "Kitchen Remodel" | "vs. Contractor Quote"

#### Accent: **Anton** (for special emphasis)
- **Use for:** Sparingly—"EXPOSED" "GOUGED" "WATCH OUT"
- **Why:** Maximum impact, but overwhelming if overused
- **Free:** Yes (Google Fonts)

### Typography Rules

1. **Minimum font size:** 60pt for mobile readability
2. **Stroke/outline:** 8-12px white or black stroke for text readability over images
3. **Letter spacing:** +5-10% for all-caps headlines
4. **Alignment:** Left or center; avoid right-align
5. **Hierarchy:** One big statement, one supporting line max
6. **Drop shadow:** 4-6px shadow at 45° for depth

**Example Hierarchy:**
```
GOUGED: $15K ← 120pt Bebas Neue, white with black stroke
Real Cost: $8,200 ← 72pt Roboto Condensed, yellow with dark stroke
```

## Template Concept 1: "Price Shock Split"

### Visual Description
Split-screen layout with dramatic price comparison.

**Layout:**
```
┌─────────────────────────────────────┐
│    CONTRACTOR QUOTE    │  REAL COST │
│                        │            │
│      $18,500          │   $9,200   │
│   [angry emoji/face]   │ [checkmark]│
│    Background: Red     │  Bg: Green │
└─────────────────────────────────────┘
```

**Detailed Specs:**

- **Background:** Vertical 50/50 split
  - Left: Alert Red (#D32F2F) with 20% opacity texture overlay
  - Right: Victory Green (#388E3C) with 20% opacity texture overlay
  
- **Divider:** 10px white vertical line down center

- **Text Layout:**
  - Top labels (small): "CONTRACTOR QUOTE" | "REAL COST"  
    Font: Roboto Condensed Bold, 48pt, all caps, white
  
  - Price numbers (hero): "$18,500" | "$9,200"  
    Font: Bebas Neue, 140pt, white with 10px black stroke
  
  - Supporting icon or emoji below price (optional)

- **Project label (bottom):** 
  "DECK BUILD BREAKDOWN" - centered, white bar background  
  Font: Roboto Condensed, 52pt

- **Logo:** Top-right corner, 120px wide

**Best For:**
- Price comparison episodes
- "Real cost" breakdowns
- Quote analysis videos

**Psychological Hook:**  
The red/green split creates instant cognitive recognition (bad/good), while the dramatic price difference drives curiosity.

## Template Concept 2: "Data Detective"

### Visual Description
Investigative theme with magnified document/quote and highlighting.

**Layout:**
```
┌─────────────────────────────────────┐
│  [Magnifying glass over quote]     │
│                                     │
│   RED FLAG:                         │
│   300% MARKUP                       │
│                                     │
│   [Project type badge bottom]      │
└─────────────────────────────────────┘
```

**Detailed Specs:**

- **Background:**  
  Blurred contractor estimate/document as background  
  Overlay: 40% dark blue gradient (#1A237E to transparent)

- **Hero Element:**  
  Magnifying glass graphic (PNG) positioned over specific line item  
  Size: 400px diameter, positioned upper-left quadrant

- **Callout Text:**
  - Label: "RED FLAG:" - Alert Red, Roboto Condensed Bold, 56pt
  - Finding: "300% MARKUP" - White, Bebas Neue, 110pt
  - Both with 8px black stroke

- **Supporting Detail (optional):**
  Arrow pointing to specific line in "document" below magnifying glass  
  Small text: "Labor: $8,500 (Fair: $2,800)"

- **Bottom Badge:**
  Rounded rectangle, Trust Blue background  
  Text: "HVAC REPLACEMENT" - White, 48pt

- **Logo:** Top-left corner, small (80px)

**Best For:**
- Deep-dive quote analysis
- "Hidden fee" exposes
- Line-item breakdowns

**Psychological Hook:**  
The magnifying glass triggers investigative curiosity. Viewers want to see "what's hidden."

## Template Concept 3: "Reaction Face + Number"

### Visual Description
Host face with shocked/concerned expression next to bold price callout.

**Layout:**
```
┌─────────────────────────────────────┐
│                                     │
│  [Face: left 40%]  │  $22,000!?    │
│   shocked/angry    │   SERIOUSLY?   │
│                    │                │
└─────────────────────────────────────┘
```

**Detailed Specs:**

- **Background:**  
  Clean Trust Blue (#2C5F8D) OR contextual project photo  
  If photo: 50% opacity white overlay for text readability

- **Face:**
  - Positioned left side, 40% of frame
  - Head/shoulders shot, direct eye contact slightly off-center
  - Emotion: shock, disbelief, concern, or protective anger
  - High contrast lighting, sharp focus
  - Cut out background or subtle vignette

- **Text Block (right 60%):**
  - Main price: "$22,000!?" - Highlight Yellow (#FFC107), Bebas Neue, 140pt
  - Reaction: "SERIOUSLY?" - White, Anton, 72pt
  - Background: Semi-transparent dark box (optional, #000000 at 30%)

- **Project Label (bottom):**
  White bar across bottom 15% of frame  
  Text: "BATHROOM RENO EXPOSED" - Trust Blue, 52pt, centered

- **Logo:** Top-right, 100px

**Best For:**
- Reaction/commentary videos
- "You won't believe" hooks
- Personal opinion pieces

**Psychological Hook:**  
Human faces drive clicks. Emotion = engagement. Viewers want to know why you're shocked.

**Note:** Requires consistent "host face" photos. Build library of expressions.

## Layout Rules (Universal)

### The "Squint Test"
If you can't read the main message from 10 feet away (or with squinted eyes), your text is too small or cluttered.

### Mobile-First Design
1. Preview every thumbnail at 320x180px before publishing
2. If text isn't readable at mobile size, increase font size or reduce words
3. High contrast is non-negotiable

### Consistency Builds Brand
- **Logo placement:** Always same position (recommend top-right or bottom-right)
- **Color usage:** Stick to palette; don't introduce random colors
- **Font pairing:** Max 2 fonts per thumbnail (display + supporting)
- **Layout rhythm:** Alternate between 2-3 templates so channel feels cohesive but not repetitive

### A/B Testing Framework
Test variations of same video thumbnail:
- Version A: Price Shock Split
- Version B: Reaction Face

Track CTR for 48 hours, keep winner. Over time, you'll learn what your audience responds to.

## Production Workflow

### Tools Needed
- **Design:** Canva Pro (easiest) or Photoshop/Figma (advanced)
- **Templates:** Create master templates with placeholder text
- **Stock photos:** Unsplash (free), or take your own project photos
- **Faces:** Build library of 10-15 reaction shot variations

### Template Creation Steps
1. Create 1280x720px canvas
2. Set up safe zones (100px padding on all sides)
3. Add background (color or photo)
4. Place text elements with proper hierarchy
5. Add logo/branding
6. Export as JPG, <2MB
7. Test at mobile size

### Thumbnail Checklist
- [ ] Readable at 320px wide (mobile size)?
- [ ] High contrast between text and background?
- [ ] One clear focal point?
- [ ] Text stroke/outline applied?
- [ ] Logo placed consistently?
- [ ] File size <2MB?
- [ ] Colors from brand palette?
- [ ] Fonts at spec (60pt+ minimum)?
- [ ] Emotional hook or curiosity gap?

## Advanced Techniques

### Create "Sets" for Series
If doing 3-part series on kitchen remodels:
- Keep same layout template
- Change only the episode number badge ("Part 1 of 3")
- Builds anticipation and binge-watching

### Use Negative Space
Don't fill every pixel. Clean backgrounds with focused elements perform better than cluttered designs.

### Thumbnail Psychology
- **Red = Warning/Problem** (use for "what to avoid")
- **Green = Solution/Win** (use for "how to save")
- **Blue = Trust/Education** (use for "data breakdown")
- **Yellow = Attention/Highlight** (use sparingly for emphasis)

### The "Curiosity Gap"
Best thumbnails answer just enough to hook, not enough to satisfy:
- ✅ "$18K → $9K" (makes you want to know how)
- ❌ "How I Saved $9K on My Deck" (less mystery)
