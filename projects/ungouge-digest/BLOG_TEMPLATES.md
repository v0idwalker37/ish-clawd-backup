## 1. YouTube-to-Blog Template

- Specific examples

- [Link to related content 1]

---

### 📌 SEO Checklist for YouTube Posts:
- [ ] Primary keyword in title, first paragraph, and at least 2 subheadings
- [ ] Video embed above the fold
- [ ] Meta description 150-160 characters

## 5. SEO Checklist for All Posts

### Before Publishing:

#### Title & Meta
- [ ] **Title**: 50-60 characters, includes primary keyword
- [ ] **Meta description**: 150-160 characters, includes keyword + CTA
- [ ] **URL slug**: Short, keyword-rich, lowercase, hyphens (not underscores)
- [ ] **Primary keyword** appears in:
  - Title
  - First 100 words
  - At least 2 H2 headings
  - Meta description
  - Image alt text

#### Content Structure
- [ ] **H1**: One per page (your title)
- [ ] **H2/H3**: Logical hierarchy, keyword variations
- [ ] **Paragraph length**: Max 3-4 sentences
- [ ] **Sentence length**: Varied, mostly under 20 words
- [ ] **Reading level**: 8th grade or below (Hemingway App)
- [ ] **Word count**: Minimum 800 words (1,200-2,000 ideal for pillar content)

#### Links
- [ ] **Internal links**: 2-4 to related posts (keyword-rich anchor text)
- [ ] **External links**: 1-3 to authoritative sources (open in new tab)
- [ ] **Link text**: Descriptive, not "click here"
- [ ] **No broken links**: Test all URLs

#### Images & Media
- [ ] **Featured image**: Min 1200x630px (optimal for social sharing)
- [ ] **Alt text**: All images have descriptive alt text with keywords
- [ ] **File names**: Descriptive, lowercase, hyphens (e.g., `solar-panel-installation-costs.jpg`)
- [ ] **Compression**: Images optimized (<200KB each)
- [ ] **Captions**: Use when adding context/attribution

#### User Experience
- [ ] **CTA**: Clear call-to-action (1-2 per post)
- [ ] **Related posts**: Links at bottom to 2-3 relevant articles
- [ ] **Table of contents**: For posts >1,500 words
- [ ] **Mobile preview**: Looks good on phone/tablet
- [ ] **Load time**: Page loads in <3 seconds

#### Schema & Technical
- [ ] **Schema markup**: Article, HowTo, FAQ, or Review as appropriate
- [ ] **Open Graph tags**: For social sharing (title, description, image)
- [ ] **Author byline**: Consistent author attribution
- [ ] **Publish date**: Accurate date (update if refreshing content)
- [ ] **Categories/tags**: 1-2 categories, 3-5 relevant tags

#### Content Quality
- [ ] **Unique**: No duplicate content from other sources
- [ ] **Accurate**: Facts/stats verified and sourced
- [ ] **Updated**: Dates, prices, regulations current
- [ ] **Actionable**: Readers can do something with this info
- [ ] **Scannable**: Bullets, bold, subheadings make it easy to skim

### Post-Publishing:

- [ ] **Social share**: Post to relevant channels with custom copy
- [ ] **Newsletter**: Include in next digest if relevant
- [ ] **Internal linking**: Update 2-3 older posts to link to this new one
- [ ] **Monitor**: Check Search Console for indexing
- [ ] **Refresh schedule**: Set calendar reminder to update in 6-12 months

## 6. Markdown Style Guide

### Frontmatter Standards

```yaml
---
title: "Primary Title - Secondary Benefit"
description: "150-160 character summary with keyword and hook"
date: 2025-02-02
author: Jason Trask
tags: [keyword-1, keyword-2, keyword-3, topic-area]
featured_image: "/images/YYYY-MM-descriptive-slug.jpg"
---
```

### Heading Hierarchy

```markdown
# H1: Post Title (Only One Per Page)

## H2: Main Section Headers

### H3: Subsections Under H2

#### H4: Rarely Needed (Use for Deep Nesting Only)
```

**Rules:**
- One H1 per post (your title)
- Don't skip levels (H2 → H4 without H3)
- Use sentence case, not Title Case
- Keep headings under 60 characters

### Text Formatting

```markdown
**Bold** for emphasis on key terms or important points
*Italic* for subtle emphasis or technical terms on first use
~~Strikethrough~~ for showing "old way" vs. new approach

> Block quotes for testimonials, direct quotes, or callouts
```

### Lists

**Unordered (bullets):**
```markdown
- Main point
  - Sub-point (indent 2 spaces)
  - Another sub-point
- Next main point
```

**Ordered (numbered):**
```markdown
1. First step
2. Second step
3. Third step
```

**Checklist:**
```markdown
- [ ] Incomplete item
- [x] Completed item
```

### Links

**Internal links:**
```markdown
[descriptive anchor text](/path/to/post)
```

**External links:**
```markdown
[source name](https://external-url.com)
```

**Best practices:**
- Use descriptive anchor text (not "click here")
- Open external links in new tab if your platform supports it
- Include `rel="nofollow"` for affiliate links

### Images

```markdown
![Alt text describing the image](/images/filename.jpg)
*Optional caption in italics below image*
```

**Alt text formula:**
`[What it is] + [context/keywords]`

Example: `Bar chart showing average solar panel costs by state in 2025`

### Embedded Media

**YouTube:**
```markdown
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>
```

**Responsive video wrapper (if your theme supports it):**
```markdown
<div class="video-wrapper">
  <iframe src="..."></iframe>
</div>
```

### Tables

```markdown
| Column 1 Header | Column 2 Header | Column 3 Header |
|-----------------|-----------------|-----------------|
| Data point 1    | Data point 2    | Data point 3    |
| Data point 1    | Data point 2    | Data point 3    |
```

**Alignment:**
```markdown
| Left-aligned | Center-aligned | Right-aligned |
|:-------------|:--------------:|--------------:|
| Text         | Text           | $1,234        |
```

### Callout Boxes / Admonitions

```markdown
**💡 Pro Tip:** [Helpful insight or shortcut]

**⚠️ Warning:** [Important caution or common mistake]

**✅ Best Practice:** [Recommended approach]

**📊 Key Stat:** [Important data point]
```

### Code Blocks

**Inline code:**
```markdown
Use `inline code` for short commands or variable names.
```

**Code blocks:**
````markdown
```language
code here
```
````

Example:
````markdown
```bash
curl -s "wttr.in/Burlington+Vermont?format=%C+%t"
```
````

### Horizontal Rules

```markdown
---
```

Use sparingly to separate major sections or before/after CTAs.

### CTAs (Call-to-Action)

**Standard format:**
```markdown
---

**[Action-oriented text]** [Link or instruction]

**Related Resources:**
- [Link 1]
- [Link 2]

---
```

**Example:**
```markdown
---

**Need help choosing the right solar installer?** [Get our free comparison guide](/resources/solar-installer-guide)

**Related Posts:**
- [How to Vet Solar Companies](/blog/vet-solar-companies)
- [Solar Panel Cost Breakdown](/blog/solar-costs-2025)

---
```

### Special Characters & Symbols

**Commonly used:**
- → (right arrow): `&rarr;` or `→`
- ✓ (checkmark): `&#10003;` or `✓`
- ✗ (X mark): `&#10007;` or `✗`
- © (copyright): `&copy;` or `©`
- $ (dollar): Escape if needed: `\$`

**Emoji usage:**
- ✅ Use sparingly for visual scanning (checklists, key points)
- ❌ Avoid in formal/technical content
- 👍 Good for conversational posts, social shares

### Line Breaks & Spacing

**Paragraph breaks:**
- Single blank line between paragraphs
- No extra spacing (avoid double line breaks)

**Hard line break:**
```markdown
Line 1  
Line 2 (two spaces at end of Line 1)
```

### Escaping Markdown

```markdown
Use backslash to escape: \*not italic\* \[not a link\]
```

## Template Usage Tips

### Which Template to Use?

| Content Type | Template |
|--------------|----------|
| Video breakdown | YouTube-to-Blog |
| Industry research, pricing analysis | Data Analysis |
| Customer success story | Case Study |
| Step-by-step tutorial | How-To Guide |

### Customization Guidelines

1. **Keep what works**: Don't feel obligated to use every section
2. **Add sections as needed**: These are starting points, not rigid rules
3. **Maintain SEO elements**: Always include frontmatter, alt text, internal links
4. **Tone**: Conversational, helpful, no jargon unless necessary
5. **Length**: Aim for 1,200-2,000 words for pillar content, 800-1,200 for supporting posts

### Workflow

1. Copy the relevant template
2. Fill in frontmatter first (helps focus the piece)
3. Write in outline form (headers + bullets)
4. Flesh out each section
5. Add media (images, videos, charts)
6. Run through SEO checklist
7. Preview on mobile
8. Publish & promote
