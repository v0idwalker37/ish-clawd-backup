## CRIT-02: Upgrade Next.js ✅
- **`frontend/package.json`** — Updated `next` from `14.2.3` → `14.2.35` (latest 14.2.x security patch). Also updated `eslint-config-next` to match.
- ⚠️ **Action required:** Run `npm install` in `frontend/` to install the update.

## CRIT-04: Fix in-memory token blacklist ✅
- **`backend/services/token_blacklist.py`** — Completely rewritten. Now uses a SQLite-backed `token_blacklist` table (via SQLAlchemy model `BlacklistedToken`) instead of an in-memory dict.
  - Tokens survive server restarts.
  - Automatic cleanup of expired tokens (probabilistic — runs ~10% of add() calls).
  - Provides both async (`TokenBlacklist`) and sync (`TokenBlacklistSync`) interfaces.
- **`backend/services/auth.py`** — Updated `verify_token()` to use `TokenBlacklistSync.is_blacklisted()` (sync shim for the sync function).
- **`backend/routers/auth.py`** — Updated logout endpoint to use `await TokenBlacklist.add()` (proper async).
- **`backend/main.py`** — Added explicit import of `BlacklistedToken` in lifespan to guarantee table creation.
- **Table creation** — The `token_blacklist` table is auto-created by `Base.metadata.create_all()` on startup.
