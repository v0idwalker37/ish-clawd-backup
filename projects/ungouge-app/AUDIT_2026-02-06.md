This audit examined the entire Ungouge.ai codebase, including backend (FastAPI/Python) and frontend (Next.js/TypeScript/React). ### 2. **In-Memory Token Blacklist Won't Survive Restart**
**File:** `backend/services/token_blacklist.py` (inferred from imports)

**Problem:** Token blacklist is stored in memory (dictionary). On server restart:
- All blacklisted tokens become valid again
- Logged-out users can re-use old tokens
- Security breach for revoked sessions

**Impact:** Authentication bypass after server restart/deployment.

**Fix:** Implement persistent storage:
```python
# Option 1: Redis-based blacklist
import redis
redis_client = redis.Redis(host='localhost', port=6379, decode_responses=True)

class TokenBlacklist:
    @classmethod
    def add(cls, token: str, expiry_seconds: int):
        redis_client.setex(f"blacklist:{token}", expiry_seconds, "1")
    
    @classmethod
    def is_blacklisted(cls, token: str) -> bool:
        return redis_client.exists(f"blacklist:{token}") > 0

# Option 2: Database table
class BlacklistedToken(Base):
    __tablename__ = "blacklisted_tokens"
    token_hash = Column(String(64), primary_key=True)  # Store hash, not raw token
    expires_at = Column(DateTime, index=True)
```

**Priority:** 🔴 **CRITICAL - Must fix before production**

### 5. **Logout Doesn't Invalidate Refresh Tokens**
**File:** `backend/routers/auth.py:373-404`

**Problem:** `/auth/logout` only blacklists access token. Refresh token remains valid, allowing attacker to generate new access tokens even after logout.

**Impact:** Session hijacking - stolen refresh token continues working after victim logs out.

**Fix:**
```python
@router.post("/auth/logout", response_model=MessageResponse)
async def logout(
    refresh_token: Optional[str] = None,  # Accept refresh token in body
    credentials: HTTPAuthorizationCredentials = Depends(security),
    current_user: User = Depends(get_current_user),
):
    access_token = credentials.credentials
    
    # Blacklist access token (existing code)
    TokenBlacklist.add(access_token, remaining_seconds)
    
    # Also blacklist refresh token if provided
    if refresh_token:
        refresh_payload = verify_token(refresh_token, token_type="refresh")
        refresh_exp = refresh_payload.get("exp")
        if refresh_exp:
            refresh_remaining = int((datetime.utcfromtimestamp(refresh_exp) - datetime.utcnow()).total_seconds())
            if refresh_remaining > 0:
                TokenBlacklist.add(refresh_token, refresh_remaining)
    
    return MessageResponse(message="Logged out successfully")
```

**Priority:** 🔴 **CRITICAL - Authentication vulnerability**

### 6. **Missing Environment Variable Validation on Startup**
**File:** `backend/main.py` and other service files

**Problem:** Critical environment variables have fallbacks or fail silently:
- `JWT_SECRET_KEY` defaults to insecure value
- `STRIPE_SECRET_KEY` defaults to empty string
- `DATABASE_URL` defaults to SQLite
- `GOOGLE_API_KEY` (for Gemini AI) no validation

**Impact:** Application starts in insecure/broken state without warning.

**Fix:**
```python
# Create config.py
import os
from typing import Optional

class Config:
    # Required in production
    REQUIRED_ENV_VARS = {
        "JWT_SECRET_KEY": "Secret key for JWT tokens",
        "STRIPE_SECRET_KEY": "Stripe API key",
        "GOOGLE_API_KEY": "Google Gemini API key",
    }
    
    # Optional with defaults
    DATABASE_URL: str = os.getenv("DATABASE_URL", "sqlite+aiosqlite:///./ungouge.db")
    ENVIRONMENT: str = os.getenv("ENVIRONMENT", "development")
    
    @classmethod
    def validate(cls):
        """Validate configuration on startup"""
        if cls.ENVIRONMENT == "production":
            missing = []
            for var, description in cls.REQUIRED_ENV_VARS.items():
                if not os.getenv(var):
                    missing.append(f"{var} ({description})")
            
            if missing:
                raise RuntimeError(
                    f"Missing required environment variables in production:\n" +
                    "\n".join(f"  - {var}" for var in missing)
                )

# In main.py lifespan:
@asynccontextmanager
async def lifespan(app: FastAPI):
    Config.validate()  # Fail fast if config is invalid
    # ... rest of startup
```

**Priority:** 🔴 **CRITICAL - Prevents production misconfigurations**

async def cleanup_expired_tokens():

### 9. **Timing Attack Vulnerability in Login**
**File:** `backend/routers/auth.py:133-136`

**Problem:** While there's a comment about preventing timing attacks with dummy password verification, the database query for `user` happens *before* password check. An attacker can measure timing differences:
- User exists: slower (DB query + password hash)
- User doesn't exist: faster (DB query fails fast + dummy hash)

**Impact:** Username enumeration through timing analysis.

**Fix:**
```python
# Always query and hash, even if email invalid
result = await db.execute(
    select(User).where(User.email == normalized_email)
)
user = result.scalar_one_or_none()

# Always compute password hash (constant time)
if user:
    password_hash = user.password_hash
else:
    # Use a realistic hash from database or generate one
    # Important: This must take same time as real password verification
    password_hash = hash_password("dummy_password_for_timing_attack_prevention")

is_valid = verify_password(credentials.password, password_hash)

# Now timing is constant regardless of whether user exists
if not user or not is_valid:
    # Single error for both cases
    raise InvalidCredentialsError()
```

### 12. **Race Condition in Quote Submission**
**File:** `backend/routers/quotes.py:46-100`

**Problem:** Quote creation and line item creation are separate operations. If second operation fails, orphaned quote exists in database.

**Current:**
```python
db.add(quote)
await db.commit()  # Quote committed

# Then add line items (might fail here)
for item in quote_data.line_items:
    line_item = QuoteLineItem(...)
    db.add(line_item)

await db.commit()  # If this fails, quote exists without items
```

**Impact:** Database inconsistency, reports fail to generate.

**Fix:**
```python
try:
    # Add quote
    db.add(quote)
    
    # Add all line items in same transaction
    for item in quote_data.line_items:
        line_item = QuoteLineItem(...)
        db.add(line_item)
    
    # Commit everything together (atomic)
    await db.commit()
    
except Exception as e:
    await db.rollback()  # Rollback entire transaction
    raise DatabaseError("quote_creation", str(e))
```

### 15. **Frontend Missing Error Boundary**
**File:** `frontend/src/app/layout.tsx`

**Problem:** No global error boundary. If any component crashes, entire app white-screens with no user feedback.

**Impact:** Poor UX, user loses work, no error reporting.

**Fix:**
```typescript
// Create components/ErrorBoundary.tsx
'use client';

import React from 'react';

export class ErrorBoundary extends React.Component<
  { children: React.ReactNode },
  { hasError: boolean; error: Error | null }
> {
  constructor(props: any) {
    super(props);
    this.state = { hasError: false, error: null };
  }

  static getDerivedStateFromError(error: Error) {
    return { hasError: true, error };
  }

  componentDidCatch(error: Error, errorInfo: React.ErrorInfo) {
    console.error('Uncaught error:', error, errorInfo);
    // Send to error tracking service (Sentry, etc.)
  }

  render() {
    if (this.state.hasError) {
      return (
        <div className="min-h-screen flex items-center justify-center">
          <div className="card max-w-md">
            <h1 className="text-2xl font-bold text-red-600 mb-4">
              Something went wrong
            </h1>
            <p className="text-gray-600 mb-4">
              We're sorry, but something unexpected happened. Please try refreshing the page.
            </p>
            <button onClick={() => window.location.reload()}>
              Refresh Page
            </button>
          </div>
        </div>
      );
    }

    return this.props.children;
  }
}

// In layout.tsx:
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <ErrorBoundary>
          {children}
        </ErrorBoundary>
      </body>
    </html>
  );
}
```

import { useState, useEffect } from 'react';

export function useOnlineStatus() {
  const [isOnline, setIsOnline] = useState(true);

    const handleOnline = () => setIsOnline(true);

}

### 30. **Missing Input Sanitization in Description Fields**

**Fix:**
```python
import html

def sanitize_string(value: str, max_length: int = 500) -> str:
    if not value:
        return ""
    
    # Escape HTML entities
    sanitized = html.escape(value)
    
    # Remove null bytes and control characters
    sanitized = ''.join(char for char in sanitized if ord(char) >= 32 or char in '\n\r\t')
    
    # Normalize whitespace
    sanitized = ' '.join(sanitized.split())
    
    # Truncate if too long
    if len(sanitized) > max_length:
        sanitized = sanitized[:max_length]
    
    return sanitized.strip()
```

async def add_request_id(request: Request, call_next):
