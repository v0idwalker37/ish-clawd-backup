## Permits: Required or Not?

| Project | Permit Usually Required? |
|---------|-------------------------|
| Roofing (full replacement) | ✅ Yes |
| HVAC replacement | ✅ Yes |
| Electrical (new circuits, panel) | ✅ Yes |
| Plumbing (new lines, water heater) | ✅ Yes |
| Structural changes | ✅ Yes |
| Windows (same-size replacement) | ❌ Usually no |
| Flooring | ❌ No |
| Painting | ❌ No |
| Cabinets (no plumbing change) | ❌ No |
| Fencing (under 6 ft, not front) | ⚠️ Varies |
| Deck (attached, over 30") | ✅ Yes |

**Always verify with your local building department.**

## Red Flag Quick Check

Before analyzing any quote, verify:

☐ Contractor is licensed (check state website)
☐ Contractor is insured (request COI)
☐ Quote is itemized (not just a total)
☐ Materials are specified (brands, grades)
☐ Timeline is provided
☐ Payment schedule is reasonable (<33% upfront)
☐ Warranty terms are included
☐ Permit responsibility is clear
