### Session Model Override Fix (Session 2)
- Problem: Config was correct (`primary: openai-codex/gpt-5.3-codex`) but session kept running Opus
- Root cause: `modelOverride: claude-opus-4-6` was set at session level, which trumps global config
- Gateway restarts DON'T clear session overrides — they're persistent per session
- Fix: `session_status(model="default")` clears the session override → falls through to global default
- **Lesson:** When model isn't switching after config changes, check session-level overrides FIRST
